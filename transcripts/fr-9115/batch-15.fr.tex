dela question; ce qui lui donne:
\[ \alpha = \alpha' = 0,\quad \beta = \beta' = 0,\quad \gamma' = -\gamma \quad\text{et}\quad \delta = \delta' = 0, \]

appartenant a l'ordonnée $y$ qui est prise de l'autre côté de
